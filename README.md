# Curio 🐇

> For future "did you know..." conversations.

Curio is an interactive archive for the things you learn, wonder about, and inevitably want to tell someone later.

It turns random curiosities into a collection of stories, puzzles, and rabbit holes — designed to feel more like exploring a strange little archive than scrolling through a website.

## What is Curio?

Curio is a personal collection of interesting things worth remembering.

The site is organised into themed collections, including:

- 🕳️ **Rabbit Holes** — strange facts and fascinating tangents
- 🧩 **Puzzles** — logic problems, riddles, and things to figure out
- 🌿 **Nature** — curious phenomena from the natural world
- 🧠 **Psychology** — interesting ideas about how people think and behave
- ⏳ **History** — stories and details from the past
- 💡 **Suggest** — a place to contribute something worth adding to the archive

Each collection has its own interactive visual background, with subtle animations and cursor interactions built with Three.js.

## Features

- Interactive collection-based archive
- Expandable entries and answers
- Animated typography
- Responsive design for desktop and mobile
- Interactive Three.js backgrounds
- Cursor-based particle and object interactions
- Interactive puzzle experience
- Suggestion form for new curiosities

## Tech Stack

## Running Locally

Clone the repository and install the dependencies:

```bash
git clone https://github.com/aadya-codes/Curio.git
cd Curio
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL provided by Vite.
